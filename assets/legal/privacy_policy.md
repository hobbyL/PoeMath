# 韵算 (PoeMath) 隐私政策

**最后更新：2026 年 10 月 21 日**

欢迎使用 **韵算 (PoeMath)**。我们非常重视您及您孩子的隐私保护。本政策说明应用如何处理数据、权限与可选网络功能，与当前软件行为保持一致。

---

## 1. 产品原则

韵算是一款**离线优先**的儿童学习应用：

1. **核心学习本地完成**：诗词背诵、口算练习、公式浏览、打卡、成就、复习计划等，**不依赖网络**，飞行模式下可用。
2. **不向开发者服务器收集个人信息**：不采集姓名、年龄、学校、手机号、设备广告标识等用于画像或运营的数据。
3. **无广告、无内购、无分析/追踪 SDK**：不集成广告平台、行为分析或崩溃上报类数据收集服务。
4. **可选能力默认关闭或需主动触发**：备份、WebDAV 同步、腾讯云语音识别、云端朗读、应用题 AI 出题、AI 讲解、AI 助手、学习提醒等，仅在您（或家长）主动使用、配置并授权时才会涉及相应权限或网络。配置更新源的版本会在启动及恢复前台时自动检查版本信息，至少间隔一小时；下载与安装由您主动确认。

---

## 2. 我们不收集什么

韵算**不会**将下列信息上传到开发者可控的远程服务器：

- 姓名、年龄、性别、学校、年级等身份信息
- 手机号、邮箱、社交账号
- 精确位置、通讯录、相册内容（应用不申请这些权限）
- 用于广告的设备标识符、Cookie 行为追踪
- 将您的学习成绩、错题内容批量上报给开发方用于分析或广告

**说明：** 学习进度、错题、收藏等主要保存在**您的设备本地**；Android 系统可能按照您的系统设置执行备份或设备迁移。开发者无法在未经过您主动备份/同步的情况下远程查看这些数据，也无法访问 Android 系统保存的备份内容。

---

## 3. 本地数据存储

应用使用设备本地存储（含 Hive 数据库、应用私有目录）保存例如：

- 诗词学习进度、收藏、复习计划
- 口算练习记录、错题本、挑战记录
- 年级/学期、固定到当天的任务清单、未完成口算/应用题的题组草稿与输入
- 诗词作答的文字明细、错句、识别文字与复习周期历史；不因此新增录音长期保存
- 打卡、星星、等级、成就
- 主题、语速、音效/触觉开关等设置
- （若您配置）WebDAV 地址等非敏感字段；WebDAV 密码和腾讯云 SecretId/SecretKey 使用系统安全存储保存
- 腾讯云识别的密钥验证指纹与验证时间；验证指纹为不可逆摘要，不包含可直接使用的 AK/SK
- （若您配置）云端朗读的自建服务地址、音色等非敏感字段；对应 API Key 使用系统安全存储保存，验证指纹为不可逆摘要
- （若您配置）应用题 AI 出题的 LLM 服务地址与模型名等非敏感字段；对应 API Key 使用系统安全存储保存
- 应用题的题面、讲解、数量关系及素材来源与题库做题记录（本地生成并保存；主动请求 AI 帮助时按所用功能发送当前内容）
- AI 助手会话、聊天文本、工具调用结果和清除上下文的切点；删除会话会删除对应本机聊天，已导出副本须另行管理
- （若您自定义）AI 讲解的讲解风格提示词文本（诗词讲解 / 口算解析的 system prompt）保存在本机设置，属用户内容，可随本地备份同步；AI 讲解复用上面「应用题 AI 出题」配置的 LLM 服务，不单独保存服务地址或 Key

在 Android 设备上，操作系统可能按照设备厂商、系统账户及您的系统备份设置，将部分应用数据保存到系统云备份，或在换机时迁移到新设备。该过程由 Android 系统提供和控制，不经过韵算开发者服务器，开发者也无法查看这些系统备份内容。

**删除方式：**

- 卸载应用会删除当前设备上的应用本地数据（重要数据请先导出备份）
- 系统云备份或设备迁移中保存的副本可能在卸载后继续保留，并在重新安装或换机时恢复；请通过设备的系统备份设置管理或删除这些副本
- 可在系统设置中撤销麦克风、通知等权限
- 可通过「备份与恢复」先导出，再卸载或清空

### 4.1 本地备份 / 恢复

- 可将学习数据、普通设置、AI 厂商/四场景绑定与助手聊天导出为 JSON 文件，或从 JSON 恢复；设置备份口令后整份备份均加密，未设置口令时这些内容以明文导出
- 可通过系统「分享」发送到您选择的应用（邮件、网盘、文件管理器等）
- **不经过**韵算开发者服务器
- WebDAV 用户名/密码不写入 JSON 备份，也不会被恢复覆盖
- 若您在「备份与恢复」中设置了备份加密口令，整份学习记录、聊天内容和腾讯云 SecretId/SecretKey、云端朗读 API Key、各厂商的 LLM API Key 均采用 AES-256-GCM 加密；恢复时必须输入同一口令才能预览，解包后可选择跳过凭据恢复。旧版仅凭据节加密的备份仍可留空口令以只恢复学习数据
- 请妥善保管备份文件，其中可能包含学习进度等个人使用记录
- 恢复前会展示日期、分类数量和服务地址变更，并保存本机保护快照；本地历史最多 10 份，不含安全凭据，并使用设备安全存储中的独立密钥整体加密。可选每日快照只在启动或回到应用时检查，不会自动上传
- 本机快照使用独立设备密钥加密，可读取的旧明文快照会在启动检查或读取时转为密文；密钥无法读取时保留原文件并提示重试。本机快照不能防止卸载或设备丢失，请另存外部备份并妥善保存加密口令
- WebDAV 保留版本文件和最新文件；删除或卸载本机应用不会自动删除服务器上的版本，请在自己的 WebDAV 服务中管理
- 未完成题组草稿、当日任务清单、家长 PIN 验证记录与设备云服务用量不随应用 JSON/WebDAV 备份迁移


设置备份口令后，新导出及 WebDAV 上传的整个备份（包括学习记录和聊天）均采用 AES-256-GCM 加密；未设置口令时外部备份为明文 JSON，请自行妥善保存。旧版仅凭据节加密的备份仍可恢复。

### 4.2 WebDAV 同步（可选）

- 默认关闭；需您自行填写服务器地址、路径、用户名与密码
- 上传/下载的是备份类数据，目标为**您指定的服务器**
- 凭据使用 `flutter_secure_storage` 等系统安全机制保存在本机
- WebDAV 用户名/密码只用于连接您指定的服务器，不作为备份内容上传，也不会被下载的备份覆盖
- 请仅使用您信任的 WebDAV 服务，并建议由家长协助配置

### 4.3 应用内更新（可选）

- 仅在构建时注入了更新检查地址（如 `UPDATE_CHECK_URL`）时可用
- 未配置时，「检查更新」入口不可用，不会发起更新请求
- 配置更新源时，启动和恢复前台会自动获取版本信息，检查之间至少间隔一小时；您也可以手动检查
- 下载 APK 与安装需您主动确认，下载后会核验完整性
- 需要网络权限及（Android）安装应用包相关能力

### 4.4 诗词跟读

- 需要麦克风权限与网络；识别由腾讯云语音识别服务完成，应用内不再内置本地识别模型
- 可由家长在「设置 → 声音与交互 → 语音识别设置」中手动填写自己的腾讯云 SecretId/SecretKey；凭据保存在系统安全存储，不写入普通设置、日志或异常信息，仅在设置备份加密口令后以加密形式随备份携带
- 未配置密钥或未通过真实录音测试时，跟读入口置灰并引导配置，不会发起录音或网络请求
- 通过真实录音测试即视为已配置；修改、删除密钥或测试失败会自动撤销该状态
- 跟读时，应用会把当前一句 PCM 录音以 Base64 编码通过 HTTPS 直接发送到腾讯云 `SentenceRecognition` 接口；网络、鉴权、额度或服务异常时本次跟读失败并提示重试，不回退本地结果
- 腾讯云账户额度、计费、数据处理与保存规则由腾讯云及用户账户配置决定。请使用最小权限的专用子账号密钥，并在怀疑泄露时立即到腾讯云控制台禁用或轮换密钥
- 跟读分数只表示识别文字与诗句的内容匹配程度，不构成声调、口音或真实发音质量评测

### 4.5 云端朗读（自建语音服务，可选）

- 默认关闭；需家长在音频设置中填写自建语音合成服务的地址与 API Key 并通过验证后，云端朗读开关才会可用
- 开启后，朗读时应用把当前一段文本逐行通过 HTTPS 直接发送到**家长自建或指定的语音合成服务**（应用内预填默认地址，可修改）；API Key 保存在系统安全存储，不写入普通设置、日志或异常信息，仅在设置备份加密口令后以加密形式随备份携带
- 合成返回的音频仅保存在内存中（最近 32 条以内的短音频），用于避免重复朗读时重复请求；不写入磁盘，退出应用即清空
- 网络、鉴权或服务异常时，当次朗读自动回退系统本地音色，不打断孩子使用；具体原因可在音频设置的音色试听中查看
- 该服务的部署位置、数据处理与保存规则由服务提供方（即配置它的家长）决定；家长可随时在音频设置中删除服务配置或关闭云端朗读

### 4.6 应用题 AI 出题（第三方 LLM 服务，可选）

- 默认关闭；需家长在设置中填写第三方 LLM 服务的地址与 API Key（OpenAI 兼容格式）后，生成功能才可用
- 生成时，应用把**年级、学期、知识点、数量关系类型及本地情境和句式候选**通过 HTTPS 直接发送到**家长自行配置的第三方 LLM 服务**，服务仅从候选中选择情境和句式；不发送操作数、算式、答案、讲解、个人信息、儿童数据、学习记录或设备标识
- 题目的数字、条件、问句、单位、答案和讲解均由本地计划与模板生成，核验数量关系、计算及学期知识点后，再由**家长预览确认**才存入本地题库。素材格式错误或缺失时，最多三次请求后由本地补齐并标明来源；取消、网络、鉴权或额度错误仍明确报错。需要复核或不可使用的题、家长取消勾选的题不保存；旧题保留原有内容与成绩，不自动授予新版校验结论
- API Key 保存在系统安全存储，不写入普通设置、日志或异常信息，仅在设置备份加密口令后以加密形式随备份携带
- 应用题做题、讲解查看、题库管理全程本地离线完成，不再访问 LLM 服务；家长可随时在设置中删除 LLM 服务配置

### 4.7 AI 讲解（诗词讲解 / 口算解析，第三方 LLM 服务，可选）

- 默认关闭；复用「应用题 AI 出题」配置的第三方 LLM 服务（OpenAI 兼容格式），家长可为「诗词讲解 / 口算解析」分别绑定不同配置，未绑定则跟随默认生效配置
- 诗词讲解仅发送该诗的标题、作者、朝代与正文；口算讲解仅发送当前题面、正确答案、孩子的作答（若有）与错因中文标签——通过 HTTPS 直接发送到**家长自行配置的第三方 LLM 服务**，用于生成儿童口语化讲解
- **不发送**姓名、年龄、年级、学期、历史学习记录或设备标识，也不成批上报错题；每次仅发送当前这一首诗或这一道题
- 讲解为即时查看，默认不额外保存；请求失败不重试，由您点「重新生成」重试；切题、切诗或关闭弹层会废弃仍在途的请求
- API Key 保存在系统安全存储，不写入普通设置、日志或异常信息，仅在设置备份加密口令后以加密形式随备份携带
- 讲解风格提示词（system prompt）内置出厂默认，家长可编辑并一键重置；该服务的数据处理与保存规则由其提供方（即配置它的家长）决定，家长可随时在设置中删除 LLM 服务配置

### 4.8 AI 助手（可选）

- 家长可独立选择助手的厂商、模型与提示词。发送消息时，会把当前上下文窗口内的用户/助手消息、工具定义及调用参数和结果发送至该服务；输入可能包含个人内容，请避免填写不必要的敏感信息
- 清除上下文会持久保存请求切点，先前消息继续在本机展示，但后续请求不再包含切点之前的聊天；如需删除展示历史，请删除会话
- 工具可打开练习、辅助讲解或生成应用题；出题仍须家长预览确认入库。停止或切换会话后，已发出的请求可能在服务端完成，应用会丢弃晚到结果并阻止其继续导航
- 会话随 JSON/WebDAV 备份迁移。第三方服务的内容保留与处理规则以该服务及账户配置为准

### 4.9 本地通知

- 用于学习提醒等，在本机调度
- Android 8+ / 13+ 可能需要通知权限；开机完成后可能恢复已调度的提醒
- 恢复本地或 WebDAV 备份后，应用会按恢复的提醒开关与时间重新调度或取消通知；系统通知权限不进入备份
- 不将通知内容上传至开发者服务器

### 4.10 Android 系统备份与设备迁移

- 应用已在 Android 新旧备份规则中排除安全存储的加密偏好文件；换机后可能需要重新配置密钥，或从带口令的应用备份恢复
- Android 可能默认为应用启用系统自动备份，并将部分应用私有数据保存到与设备关联的系统备份服务
- 换机、重新安装或设备迁移时，操作系统可能把备份数据恢复到新安装的韵算中
- 是否执行、备份范围、保留期限和删除方式取决于 Android 版本、设备厂商、系统账户及您的系统设置
- 这些系统备份不经过韵算开发者服务器，开发者无法访问；您可在设备的系统备份设置中查看、关闭或管理相关备份

### 4.11 家长保护与云服务次数

- 家长保护可选、默认关闭。启用时设置本机 6 位 PIN 并取得一次性恢复码，系统安全存储只保存加盐摘要，不保存 PIN/恢复码原文，也不上传给开发者
- 解锁有效 2 分钟，切到后台立即锁定；连续错误尝试会暂时限制重试。恢复码使用后关闭保护，可重新设置；请自行妥善保存恢复码
- 应用备份不包含保护验证记录。系统迁移后若安全摘要确实缺失，需重新设置；安全存储读取异常不会按“缺失”直接放行
- 本机按日期保存 AI、识别、云朗读的请求次数和家长设置的额度。默认每日上限分别为 30/60/120 次，家长可调整、暂停或明确选择不限，不上报给开发者
- 已发送请求的失败、连接测试、重试、多轮调用也计数，朗读缓存命中不计数；额度是设备内的请求次数控制，不是云服务金额上限，也不能替代服务商账户的费用控制
- 家长保护是应用内操作保护，不用于防御掌握设备或系统控制权的人员

## 6. 第三方服务与 SDK

- **无**广告 SDK、**无**统计分析 SDK、**无**商业崩溃收集 SDK（如面向运营的 Firebase Analytics / AdMob 等）
- 使用 `record` 获取用户主动触发的跟读录音；录音仅用于当次识别，识别完成后不在本机保留
- **腾讯云语音识别**是家长可选配置的第三方服务。应用使用家长提供的账户密钥直接调用腾讯云接口，仅在真实录音测试或已配置跟读时发送当句录音；腾讯云的隐私和数据处理规则以腾讯云公开政策及账户协议为准
- **云端朗读**使用家长自建或指定的语音合成服务（非韵算开发者服务器）。应用仅在家长开启云端朗读时向该服务发送当行文本；该服务的隐私和数据处理规则由其提供方（即配置它的家长）决定
- **应用题 AI 出题**使用家长自行配置的第三方 LLM 服务（OpenAI 兼容接口，非韵算开发者服务器）。应用仅在家长主动生成题目时发送年级、学期、知识点、数量关系类型和情境/句式候选，不含个人信息与学习记录；该服务的隐私和数据处理规则由其提供方（即配置它的家长）决定
- **AI 讲解**（诗词讲解 / 口算解析）复用上述第三方 LLM 服务。应用仅在您主动点击讲解时发送当前这一首诗（标题 / 作者 / 朝代 / 正文）或这一道题（题面 / 正确答案 / 孩子作答 / 错因标签），不含身份信息、设备标识或成批学习记录；该服务的隐私和数据处理规则由其提供方（即配置它的家长）决定
- 其他开源库（如 Flutter 插件）用于本地存储、UI、TTS、文件选择、分享、HTTP 客户端等工程能力，**不以收集儿童个人信息为目的**
- 系统分享、文件选择、TTS、系统备份与设备迁移属于**操作系统或您选择的目标应用**能力；其隐私实践以系统及对应应用的政策为准
