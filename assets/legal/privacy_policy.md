# 韵算 (PoeMath) 隐私政策

**最后更新：2026 年 10 月 4 日**

欢迎使用 **韵算 (PoeMath)**。我们非常重视您及您孩子的隐私保护。本政策说明应用如何处理数据、权限与可选网络功能，与当前软件行为保持一致。

---

## 1. 产品原则

韵算是一款**离线优先**的儿童学习应用：

1. **核心学习本地完成**：诗词背诵、口算练习、公式浏览、打卡、成就、复习计划等，**不依赖网络**，飞行模式下可用。
2. **不向开发者服务器收集个人信息**：不采集姓名、年龄、学校、手机号、设备广告标识等用于画像或运营的数据。
3. **无广告、无内购、无分析/追踪 SDK**：不集成广告平台、行为分析或崩溃上报类数据收集服务。
4. **可选能力默认关闭或需主动触发**：备份、WebDAV 同步、检查更新、腾讯云语音识别、云端朗读、应用题 AI 出题、学习提醒等，仅在您（或家长）主动使用、配置并授权时才会涉及相应权限或网络。

---

## 2. 我们不收集什么

韵算**不会**将下列信息上传到开发者可控的远程服务器：

- 姓名、年龄、性别、学校、年级等身份信息
- 手机号、邮箱、社交账号
- 精确位置、通讯录、相册内容（应用不申请这些权限）
- 用于广告的设备标识符、Cookie 行为追踪
- 将您的学习成绩、错题内容批量上报给开发方用于分析或广告

**说明：** 学习进度、错题、收藏等主要保存在**您的设备本地**；Android 系统可能按照您的系统设置执行备份或设备迁移。开发者无法在未经过您主动备份/同步的情况下远程查看这些数据，也无法访问 Android 系统保存的备份内容。

## 3. 本地数据存储

应用使用设备本地存储（含 Hive 数据库、应用私有目录）保存例如：

- 诗词学习进度、收藏、复习计划
- 口算练习记录、错题本、挑战记录
- 打卡、星星、等级、成就
- 主题、语速、音效/触觉开关等设置
- （若您配置）WebDAV 地址等非敏感字段；WebDAV 密码和腾讯云 SecretId/SecretKey 使用系统安全存储保存
- 腾讯云识别的密钥验证指纹与验证时间；验证指纹为不可逆摘要，不包含可直接使用的 AK/SK
- （若您配置）云端朗读的自建服务地址、音色等非敏感字段；对应 API Key 使用系统安全存储保存，验证指纹为不可逆摘要
- （若您配置）应用题 AI 出题的 LLM 服务地址与模型名等非敏感字段；对应 API Key 使用系统安全存储保存
- 应用题 AI 出题生成的题面、讲解与题库做题记录（仅存本机，不联网）

在 Android 设备上，操作系统可能按照设备厂商、系统账户及您的系统备份设置，将部分应用数据保存到系统云备份，或在换机时迁移到新设备。该过程由 Android 系统提供和控制，不经过韵算开发者服务器，开发者也无法查看这些系统备份内容。

**删除方式：**

- 卸载应用会删除当前设备上的应用本地数据（重要数据请先导出备份）
- 系统云备份或设备迁移中保存的副本可能在卸载后继续保留，并在重新安装或换机时恢复；请通过设备的系统备份设置管理或删除这些副本
- 可在系统设置中撤销麦克风、通知等权限
- 可通过「备份与恢复」先导出，再卸载或清空

## 4. 功能与数据处理对照

| 功能 | 是否需要网络 | 数据去向 | 触发方式 |
|------|-------------|---------|---------|
| 诗词 / 口算 / 公式 / 打卡 / 成就 | 否 | 仅本机 | 日常使用 |
| TTS 朗读 | 默认否*；开启云端朗读后是 | 默认由系统 TTS 引擎本地处理；开启云端朗读后，当前朗读的文本逐行发送至家长自建或指定的语音合成服务，返回的音频仅在内存中短期缓存用于当次及近期重复朗读，不写入磁盘 | 您点击朗读，且家长已在音频设置中配置服务并开启「云端朗读音色」 |
| 本地备份 / 恢复 | 否 | 导出 JSON 到本机目录或系统分享目标（由您选择） | 设置中主动操作 |
| Android 系统备份 / 设备迁移 | 视系统设置而定 | Android 系统备份服务或目标设备 | 由操作系统按您的系统设置执行 |
| WebDAV 云端同步 | 是 | **仅您填写的 WebDAV 服务器**（非韵算自有云） | 您配置并点击上传/下载 |
| 检查更新 / 安装 APK | 是 | 构建时配置的更新源（如下载 `latest.json` 与 APK） | 您点击「检查更新」且已配置更新地址 |
| 诗词跟读（腾讯云识别，可选） | 是 | 录音结束时将当前一句 PCM 录音发送至腾讯云语音识别服务；识别文字用于内容匹配 | 家长填写 AK/SK、通过真实录音测试后启用；未配置时跟读入口置灰 |
| 应用题 AI 出题（可选） | 仅生成时是 | 题目数字结构（年级、学期、知识点、算式骨架）发送至**家长自行配置的第三方 LLM 服务**；不含任何个人信息、儿童数据、学习记录或设备标识 | 家长已在设置中配置 LLM 服务并主动点击生成 |
| 每日学习提醒 | 否 | 本机定时通知 | 您开启提醒并授权通知 |

\* 部分系统 TTS 引擎由操作系统提供；韵算不把朗读文本发往开发者服务器。云端朗读仅在家长显式配置并开启后使用家长自建或指定的语音合成服务，且可随时在音频设置中关闭，关闭后立即恢复系统本地朗读。

### 4.1 本地备份 / 恢复

- 可将学习数据导出为 JSON 文件，或从 JSON 恢复
- 可通过系统「分享」发送到您选择的应用（邮件、网盘、文件管理器等）
- **不经过**韵算开发者服务器
- WebDAV 用户名/密码不写入 JSON 备份，也不会被恢复覆盖
- 若您在「备份与恢复」中设置了备份加密口令，腾讯云 SecretId/SecretKey、云端朗读 API Key 与应用题 AI 出题的 LLM API Key 会以口令加密形式（AES-256-GCM）随备份携带；恢复时输入同一口令即可还原，留空则跳过凭据、仅恢复学习数据
- 请妥善保管备份文件，其中可能包含学习进度等个人使用记录

### 4.2 WebDAV 同步（可选）

- 默认关闭；需您自行填写服务器地址、路径、用户名与密码
- 上传/下载的是备份类数据，目标为**您指定的服务器**
- 凭据使用 `flutter_secure_storage` 等系统安全机制保存在本机
- WebDAV 用户名/密码只用于连接您指定的服务器，不作为备份内容上传，也不会被下载的备份覆盖
- 请仅使用您信任的 WebDAV 服务，并建议由家长协助配置

### 4.3 应用内更新（可选）

- 仅在构建时注入了更新检查地址（如 `UPDATE_CHECK_URL`）时可用
- 未配置时，「检查更新」入口不可用，不会发起更新请求
- 您点击检查后，应用可能下载版本信息与 APK，并在校验后请求安装
- 需要网络权限及（Android）安装应用包相关能力

### 4.4 诗词跟读

- 需要麦克风权限与网络；识别由腾讯云语音识别服务完成，应用内不再内置本地识别模型
- 可由家长在「设置 → 声音与交互 → 语音识别设置」中手动填写自己的腾讯云 SecretId/SecretKey；凭据保存在系统安全存储，不写入普通设置、日志或异常信息，仅在设置备份加密口令后以加密形式随备份携带
- 未配置密钥或未通过真实录音测试时，跟读入口置灰并引导配置，不会发起录音或网络请求
- 通过真实录音测试即视为已配置；修改、删除密钥或测试失败会自动撤销该状态
- 跟读时，应用会把当前一句 PCM 录音以 Base64 编码通过 HTTPS 直接发送到腾讯云 `SentenceRecognition` 接口；网络、鉴权、额度或服务异常时本次跟读失败并提示重试，不回退本地结果
- 腾讯云账户额度、计费、数据处理与保存规则由腾讯云及用户账户配置决定。请使用最小权限的专用子账号密钥，并在怀疑泄露时立即到腾讯云控制台禁用或轮换密钥
- 跟读分数只表示识别文字与诗句的内容匹配程度，不构成声调、口音或真实发音质量评测

### 4.5 云端朗读（自建语音服务，可选）

- 默认关闭；需家长在音频设置中填写自建语音合成服务的地址与 API Key 并通过验证后，云端朗读开关才会可用
- 开启后，朗读时应用把当前一段文本逐行通过 HTTPS 直接发送到**家长自建或指定的语音合成服务**（应用内预填默认地址，可修改）；API Key 保存在系统安全存储，不写入普通设置、日志或异常信息，仅在设置备份加密口令后以加密形式随备份携带
- 合成返回的音频仅保存在内存中（最近 32 条以内的短音频），用于避免重复朗读时重复请求；不写入磁盘，退出应用即清空
- 网络、鉴权或服务异常时，当次朗读自动回退系统本地音色，不打断孩子使用；具体原因可在音频设置的音色试听中查看
- 该服务的部署位置、数据处理与保存规则由服务提供方（即配置它的家长）决定；家长可随时在音频设置中删除服务配置或关闭云端朗读

### 4.6 应用题 AI 出题（第三方 LLM 服务，可选）

- 默认关闭；需家长在设置中填写第三方 LLM 服务的地址与 API Key（OpenAI 兼容格式）后，生成功能才可用
- 生成时，应用把**题目的数字结构**（年级、学期、知识点与本地预生成的算式骨架）通过 HTTPS 直接发送到**家长自行配置的第三方 LLM 服务**，用于把算式包装成应用题情境文本与解题讲解；**不发送**任何个人信息、儿童数据、学习记录或设备标识
- 服务返回的题面与讲解需通过应用内置的本地校验（数字一致性、语义一致、数学正确、形态约束），再由**家长预览确认**后才存入本地题库；被校验拒绝或家长取消勾选的草稿不保存
- API Key 保存在系统安全存储，不写入普通设置、日志或异常信息，仅在设置备份加密口令后以加密形式随备份携带
- 应用题做题、讲解查看、题库管理全程本地离线完成，不再访问 LLM 服务；家长可随时在设置中删除 LLM 服务配置

### 4.7 本地通知

- 用于学习提醒等，在本机调度
- Android 8+ / 13+ 可能需要通知权限；开机完成后可能恢复已调度的提醒
- 恢复本地或 WebDAV 备份后，应用会按恢复的提醒开关与时间重新调度或取消通知；系统通知权限不进入备份
- 不将通知内容上传至开发者服务器

### 4.8 Android 系统备份与设备迁移

- Android 可能默认为应用启用系统自动备份，并将部分应用私有数据保存到与设备关联的系统备份服务
- 换机、重新安装或设备迁移时，操作系统可能把备份数据恢复到新安装的韵算中
- 是否执行、备份范围、保留期限和删除方式取决于 Android 版本、设备厂商、系统账户及您的系统设置
- 这些系统备份不经过韵算开发者服务器，开发者无法访问；您可在设备的系统备份设置中查看、关闭或管理相关备份

## 5. Android 权限说明

以下权限与当前 `AndroidManifest` 声明一致，用途如下：

| 权限 | 用途 | 是否可拒绝 |
|------|------|-----------|
| `INTERNET` | WebDAV、检查更新、可选腾讯云语音识别、云端朗读与应用题 AI 出题等网络功能 | 系统级声明；不使用相关功能时不发起网络请求 |

## 6. 第三方服务与 SDK

- **无**广告 SDK、**无**统计分析 SDK、**无**商业崩溃收集 SDK（如面向运营的 Firebase Analytics / AdMob 等）
- 使用 `record` 获取用户主动触发的跟读录音；录音仅用于当次识别，识别完成后不在本机保留
- **腾讯云语音识别**是家长可选配置的第三方服务。应用使用家长提供的账户密钥直接调用腾讯云接口，仅在真实录音测试或已配置跟读时发送当句录音；腾讯云的隐私和数据处理规则以腾讯云公开政策及账户协议为准
- **云端朗读**使用家长自建或指定的语音合成服务（非韵算开发者服务器）。应用仅在家长开启云端朗读时向该服务发送当行文本；该服务的隐私和数据处理规则由其提供方（即配置它的家长）决定
- **应用题 AI 出题**使用家长自行配置的第三方 LLM 服务（OpenAI 兼容接口，非韵算开发者服务器）。应用仅在家长主动生成题目时向该服务发送题目数字结构（年级、学期、知识点、算式骨架），不含个人信息与学习记录；该服务的隐私和数据处理规则由其提供方（即配置它的家长）决定
- 其他开源库（如 Flutter 插件）用于本地存储、UI、TTS、文件选择、分享、HTTP 客户端等工程能力，**不以收集儿童个人信息为目的**
- 系统分享、文件选择、TTS、系统备份与设备迁移属于**操作系统或您选择的目标应用**能力；其隐私实践以系统及对应应用的政策为准

## 7. 儿童隐私

韵算面向约 **6–12 岁** 学生，并遵循以下原则：

- 不要求注册账号，不建立面向儿童的社交关系
- 不展示广告，不提供内购
- 可选网络与敏感权限默认不强制；建议**家长协助**管理：
  - WebDAV 服务器与密码
  - 腾讯云账户、AK/SK（跟读识别）
  - 自建语音服务地址与 API Key（云端朗读）
  - LLM 服务地址与 API Key（应用题 AI 出题）
  - 是否允许检查更新与安装 APK
  - 麦克风、通知权限
  - Android 系统备份与设备迁移设置
  - 备份文件的存放与分享对象
