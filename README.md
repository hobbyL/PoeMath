## 简介

**韵算 (PoeMath)** 是一款面向中国小学生（6–12 岁）的**离线优先**每日学习助手，覆盖**语文学习与数学练习**。核心学习与记录以本机处理为主，无广告、无内购，不向开发者服务器收集个人信息。

- 📚 **语文学习** — 在「课本、表达、诗词」三个栏目中切换，学习已添加的教材、练习识字写字和看图说话，或进行古诗词背诵、测试与间隔复习。课本按当前年级、学期展示，首次默认课本，此后记住上次栏目及列表位置。
- 🔢 **数学练习** — 1–6 年级 12 个学期按知识点生成口算题，12 类题型覆盖加减乘除、进退位、混合运算及小数 / 分数 / 百分数 / 方程 / 比例；支持应用题、错题回练、分步讲解与 60+ 公式知识库。

🎯 游戏化激励（打卡 → 星星 → 等级 → 勋章）与音效 / 触觉反馈，让每天一练更有动力。教材下载、WebDAV 同步、应用内更新、腾讯云语音识别、云端朗读和家长自配服务的 AI 出题 / 讲解均为按需使用的可选能力。Flutter · Android 优先 · Apache-2.0 开源。

静态资源包含 1031 条兼容记录，对应 1022 个独立作品；重复 ID 通过固定别名合并进度、收藏和复习，旧链接仍可打开。作者 389 位，公式 65 条。

### 核心特色

- 📚 **课本学习与字词练习**：下载或导入教材 PDF，支持原书阅读、目录、搜索与续读；课文内容、字词、背诵范围和习题按本机整理的课程展示，支持朗读、认字、书写与随机听写，结构化内容仍需家长逐课核验
- 🗣️ **看图说话表达**：家长整理题图与引导问题，孩子观察图片后点击「说一说」分段录音、回听并修改识别文字；完成练习后保存本机记录，支持本地反馈和可选 AI 反馈
- 🏮 **1000+ 首古诗词**：核心层约 130 首（部编教材向）+ 扩展层约 400 首 + 探索层；支持年级/朝代/作者/主题浏览
- 🧮 **12 类口算题型**：紧贴人教版数学课标，1-6 年级 12 个学期配置
- 🎚️ **分档出题**：口算与应用题自动沿用练习设置中的简单 / 中等 / 困难；困难口算优先进退位和较难乘除组合，整组题目去重并平衡知识点与题型。应用题增加求原数、逆向比较，二年级困难档可选两步混合题，仍校验表内乘除与中间数量范围
- 📅 **统一学习背景与今日任务**：引导/设置保存年级和学期，今日复习、错题、新学清单固定到当天；家长可调整次日数量与顺序，教材路线按当前册次/单元区分必背与拓展
- 🎯 **按知识点回练**：同类新题限定进位、退位、口诀、余数等知识点；临时专项不改常用偏好，旧错题缺少元数据时保留原题回练
- ✍️ **普通 / 竖式方案**：练习与挑战开始前选择，按当前年级、学期和难度开放；非负整数加减乘竖式按数位填写结果并判分，无需填写进位/借位，小数竖式填写完整结果；竖式错题按原题回练
- 📐 **60+ 数学公式库**：分类浏览、参数说明、记忆技巧、例题，三区域点击朗读（符号口语化读音）
- 🎯 **智能错题分析**：6 类运算错因规则（进位遗漏/退位遗漏/口诀错误/运算顺序/余数/小数点）及竖式过程检查
- 📝 **诗词测试**：填空（补全诗句）+ 选择题（上句选下句 / 选作者 / 选朝代），自动生成题目、即时反馈
- 📖 **渐进式背诵**：首字提示 → 半隐模式 → 全隐模式 → 默写，四级递进；全文默写正确率达 80% 才通过，未通过仍记录练习；独立听写记录学习次数、时长与按正确率计算的奖励
- 🧠 **艾宾浩斯复习**：间隔 [1, 3, 7, 14, 30] 天的科学复习调度，首页提醒 + 复习列表
- 📝 **错句与复习历史**：保存诗词作答文字与差异，可只练错句；专项不代替全诗掌握、不领取整诗奖励，完成五轮后可保留历史并开启新周期
- ▶️ **中断续练**：普通口算和应用题保留题组、位置、输入和已答结果，首页继续/放弃；只计前台用时，恢复不重复计数与奖励。限时挑战切后台即结束结算，不支持续练
- 📊 **学习质量报告**：区分新学首数、练习次数、完成复习与新增掌握，按知识点显示实际答对/总题数、样本量和变化；历史未知与小样本明确标注，建议可直接进入专项
- ⭐ **游戏化激励**：每日打卡 → 星星累积 → 等级晋升（童生→状元→诗仙）→ 成就勋章
- 🎉 **感官反馈**：自研 confetti 粒子特效、flutter_animate 庆祝弹窗、音效、触觉反馈
- 💾 **数据备份/恢复**（可选）：一键导出学习数据为 JSON，跨设备恢复
- ☁️ **WebDAV 云端同步**（可选）：同步到**用户自有** WebDAV，凭据加密存储
- 🔄 **应用内更新**（可选）：检查新版本、下载 APK、校验安装（需配置更新源）
- 🎙️ **腾讯云语音识别**（可选）：优先使用腾讯云实时识别，仅当实时资源包耗尽时改用一句话识别；APPID 默认自动获取，也可手动填写。家长填写 AK/SK 并通过真实录音测试后启用诗词跟读，未配置时跟读入口置灰引导
- 🔊 **云端朗读音色**（可选）：家长自建语音合成服务逐行合成（默认晓晓诗词范读），音色目录在线拉取 + 内置精选兜底，失败自动回退系统音色；服务地址与 API Key 在音频设置中配置并验证，默认关闭
- 🤖 **AI 应用题出题**（可选）：家长自配 OpenAI 兼容大模型，本地确定数量关系、单位、答案与讲解，AI 从受控候选中选择生活情境和句式。校验后由家长预览确认入库；素材缺失时明确标注本地生成。出题只发送年级、学期、知识点、关系类型及素材候选，不传个人或学习记录，默认关闭
- 🖼️ **AI 看图说话出题**（可选）：独立配置生图服务，与普通供应商共用多配置列表、模型拉取与多选、连接测试和编辑弹窗。主题多选，通过滑动条选择每次 1–5 道单图题；先生成图片，再根据实际画面出题，兼容 SSE 流式与普通 JSON 响应。支持暂停续做、复用原图重试、编辑与选择入库；宽屏预览采用多列瀑布流，受家长验证与独立生图额度保护。[配置说明](docs/picture-story-ai-generation.md)
- ✨ **AI 讲解**（可选）：诗词详情、口算练习与错题详情一键生成儿童口语化讲解（分段展示、可朗读、可重新生成）；讲解提示词内置默认且可编辑可重置，应用题、诗词讲解、口算解析、助手和看图说话出题五个场景可各自绑定厂商；未配置时引导去设置，默认关闭
- 💬 **AI 助手**（可选）：多会话与流式回答，清除请求上下文后保留展示历史，工具可辅助打开练习和生成题目；聊天及工具结果按当前上下文发送到所选服务
- 📝 **AI 提示词设置**：应用题出题、看图说话生图、根据图片出题、诗词讲解、口算解析和助手人设均可分别查看、编辑和恢复默认，随设置备份迁移。看图说话的生图要求用于场景规划与实际生图，根据图片出题使用独立提示词；旧教学偏好保留，分别恢复默认互不影响。
- 🔁 **AI 服务自动切换**：先尝试当前供应商的已选模型，全部不可用时按配置列表顺序尝试其他已配置供应商；成功后保存可用模型，并更新全局默认供应商或当前场景的显式绑定。流式正文输出后中断会保留内容和错误提示。每次发送均计入云额度，重试可能增加等待与服务用量
- ⚙️ **分组设置中心**：首页依次展示外观与反馈、学习与内容、AI 与语音、家长与数据、应用与提醒五类入口，进入分类后配置具体项目；书籍与题库归入学习内容，家长保护、存储管理与备份同步集中管理
- 🧹 **存储管理**：在“设置 → 家长与数据”查看教材封面/解析/朗读、云朗读和图片内存缓存，以及更新、文件选择、分享和系统朗读的临时文件，可逐项确认清理。“看图说话题图”单独显示文件数量与磁盘占用，不提供清理按钮；删除题目时仅回收无引用题图，保留历史、未完成练习、草稿和其他题目仍使用的图片。磁盘与内存占用分别统计
- 🔒 **隐私友好**：不收集个人信息到开发者服务器；无广告、无内购、无分析追踪 SDK
- 👪 **设置与管理家长控制**：首次进入设置先建立本机 PIN；已设置时验证密码，15 分钟内免重复验证，切到后台立即锁定；支持一次性恢复码及 AI/识别/云朗读每日请求额度

### 设置与数据边界

设置首页只展示五个类别，点击进入子设置页后配置具体项目：

| 分类 | 内容 |
|------|------|
| 外观与反馈 | 国风/童趣主题、跟随系统/浅色/深色、页面动画、音效、练习音效、触觉反馈 |
| 学习与内容 | 学习背景、练习参数与每日目标、书籍管理、看图说话题库 |
| AI 与语音 | AI 服务/场景/提示词、独立生图配置、TTS 音色与语速、云端朗读音色、语音识别 |
| 家长与数据 | 家长密码与恢复码、云请求额度、存储管理、本地 JSON 备份/恢复、WebDAV 同步 |
| 应用与提醒 | 每日提醒与周报、版本、应用更新、隐私政策、开源许可 |

「外观与反馈 → 页面动画」默认开启淡入上滑转场和内容逐项入场；关闭后使用平台默认 push/返回动画，内容直接显示。选择会保存，并随 JSON/WebDAV 备份迁移。

「家长与数据 → 存储管理」仅扫描本机可再生缓存与已知临时副本，不触发下载或生成。逐项清理后刷新占用；正在使用的缓存需等操作结束后重试，文件选择缓存清理前会先恢复待处理的选图。旧版语音模型仅在存在遗留文件时展示。云端朗读音频清理后再次生成可能消耗云额度。

JSON/WebDAV 备份覆盖学习记录、普通设置、AI 厂商与五场景绑定、独立生图配置、助手会话及上下文切点、活动结算幂等标记，以及看图说话的新增与修改题目、所有保留版本、题图和各孩子的启用选择。设置口令后整份备份加密；未设置口令时内容与图片以明文导出，请妥善保管文件和分享对象。题图计入 32 MiB 整包上限，缺图、坏图或超限会明确报错。

同步覆盖核对（2026-11-01）：新增持久化数据需明确接入导出、校验与恢复流程，并增加实际往返测试。

| 数据范围 | 当前 JSON/WebDAV 同步范围 |
|----------|-------------------------|
| 学习记录、错题、收藏、统计、打卡与成就 | 已覆盖 |
| 诗词逐句作答、错句专项和复习历史 | 已覆盖，随练习明细和复习计划迁移 |
| AI 厂商、场景绑定、独立生图配置、提示词与助手会话 | 已覆盖；密钥需设置备份口令 |
| 学习背景、提醒、主题、页面动画、音效等普通偏好 | 已覆盖 |
| 看图说话题目、题图、保留版本、删除状态与启用选择 | 已覆盖；练习历史、录音与临时编辑表单留在本机 |
| 教材 PDF、书目与阅读位置、课程审核、识字/写字/习题专属进度 | 未纳入当前同步 |
| WebDAV 连接、云朗读服务配置与本机验证状态、缓存和草稿、PIN/恢复码、已用云额度 | 本机状态，不随当前同步迁移 |

看图说话题库初始为空，家长可新增、编辑和查看完整详情，使用相册、文件或拍照选图。新增和编辑页面通过导航栏右侧的保存图标提交，无需选择难度。图片复制到本机私有目录，长边最多 1600 像素、PNG 最多 2 MiB，可离线练习。题库由本机所有孩子共用，启用选择分别保存；新题默认只为当前孩子启用，也可在保存前关闭。选图返回或 Android 重建后恢复临时表单，家长解锁后仍需明确保存。编辑保留旧题版本，已开始的练习与历史按原版本显示；旧版内置题仅用于还原历史，已编辑保存的题目仍在题库中。题目详情右上角可删除题目，确认后从所有孩子的题库移除；原题版本、题图和已有练习记录保留，删除状态随题库备份迁移。旧备份缺少题库段时保留本机题库；明确空题库段则恢复为空题库。临时表单、看图说话练习历史和录音不随 JSON/WebDAV 迁移。

腾讯云 SecretId/SecretKey、云端朗读 API Key、各 AI 厂商 API Key 只在设置备份口令后，以 AES-256-GCM 加密形式携带；恢复时输入同一口令还原，留空跳过凭据。WebDAV 用户名/密码始终不进入备份。恢复旧版、不含助手字段的备份会保留本机聊天；含明确空会话列表则清空聊天。

WebDAV 上传/下载的是完整快照，并非记录级自动合并；覆盖其他设备较新备份前会提示冲突。恢复后刷新主题与助手缓存，并按恢复的提醒开关和时间重新调度通知；系统通知权限仍由设备管理。

每日学习提醒和学习周报支持 Android 应用图标角标：每条未查看的提醒计数为 1，打开应用或回到前台后清除已查看的通知和角标，后续定时提醒继续生效。数字角标需系统桌面支持，部分桌面只显示圆点；显示方式及通知权限由系统设置控制，未读状态不随备份迁移。

恢复前先校验固定文件内容，预览日期、各类记录数及服务地址变更，确认后保存本地保护快照再覆盖。本地历史最多保留 10 份，均不包含安全凭据；可选择每日启动/回到应用时创建快照，并开启超过 7 天的外部备份提醒。WebDAV 同时保存版本文件与兼容的最新文件，并在服务器支持时尽力保留最近 10 个版本。本地快照会随卸载丢失，不能替代外部备份。

设置首页、大模型、语音、书籍管理、看图说话题库、备份同步及同类管理入口统一需要家长密码。未设置时直接进入家长设置，建立并确认 6 位数字 PIN、保存一次性恢复码后返回原入口；已设置时先验证密码，解锁有效 15 分钟，期间切换设置免重复验证，切到后台立即锁定。取消验证保持锁定，普通学习和儿童阅读不要求先设置密码。家长页通过导航右侧的“修改家长密码”图标打开弹窗，确认两次新 PIN 后生成新恢复码，旧 PIN 与恢复码失效，家长保护继续生效；取消修改不保存，保存前再次检查家长授权。恢复码只显示一次，使用恢复码后必须重新设置密码才能继续管理。PIN/恢复码只保存加盐摘要，不进入应用备份；系统迁移导致本机摘要确实缺失时需重新设置，安全存储读取失败或记录损坏不会自动放行。此功能用于应用内操作保护，不是设备级安全隔离。

云调用默认每日上限为 AI 30 次、图片生成 10 次、语音识别 60 次、云朗读 120 次，家长可调整、设为 0 暂停或明确选择不限。连接测试、实际发送后的失败、重试和助手多轮调用均计数；云朗读缓存命中不计数，达额时回退系统朗读。额度偏好随设置备份迁移，已用计数保留在本机，不通过恢复备份归零，也不等于供应商账单金额。跟读显示的是识别文字的内容匹配参考分，支持重录和家长核对，不评价音准或声调。

题组草稿和当日任务清单保存在本机，不随应用备份迁移；成功恢复学习数据后失效并重新安排，避免旧草稿重放结算。旧记录缺少知识点、逐句作答或首次掌握日期时，报告保留“未知”边界，不补造学习结果。

教材 PDF、目录/逐页文字缓存、书目、核对状态和阅读位置保存在本机，不进入当前 JSON/WebDAV 备份。下载直接请求公开 GitHub 来源，来源服务器会收到 IP 地址及所选文件路径，不发送档案、阅读位置或教材文字。下载、导入和阅读不修改现有学习年级/学期；本书搜索和自动目录识别均在本机处理，关键词不持久保存；识别完成的目录树和逐页文字按PDF哈希缓存在应用私有目录，退出或重启后复用，删除原书时一并清理，教材文字不上传给 AI 服务。原始 PDF 和派生缓存未额外加密，存放在应用私有目录；Android 系统备份范围由系统设置决定。

开发期结构化课程使用独立的[数据模型与审核工具](tools/textbook_importer/COURSE_SCHEMA.md)：支持课文段落、逐字注音、认写字、阅读/听写词语、背诵范围和习题，逐项保留来源与审核状态。12册书库教材下载或同SHA导入后，首次进入“内容审核”会完全在本机从PDF自动整理待审草稿，逐课保存、支持暂停续跑，不调用AI或OCR。可在App内新增和编辑内容、调整范围、拆合段落、补齐候选并审核；原书异常拼音编码和不确定归属保留待处理，重试保留人工修改并显示生成差异。更多菜单保留课程JSON导入与导出，外部schema v1兼容。未审或许可未确认的草稿不能发布。课程草稿与审核人、说明保存在私有目录，未额外加密，不上传、不进JSON/WebDAV备份，移除PDF时保留；全册内容仍需逐课核验。

教材详情与原书阅读支持点击书页左下角翻上一页、右下角翻下一页；双页模式按展开页翻页，封面独立。原有底部翻页按钮、详情滑动和原书缩放继续可用，翻页后沿用原有阅读位置保存流程。

教材详情的「读一读」可查看整篇课文，并通过导航栏右侧按钮连续朗读当前页对应的课目。首段优先生成，播放时提前准备后两段；按完整句组合，正文随片段高亮。页面保留拼音，合成只使用正文与停顿标点。系统和云端音色都支持暂停后从原位置继续，返回、切换页面或进入后台自动停止。Android 系统音色由独立引擎生成WAV，云端复用现有服务生成MP3；本机私有音频缓存最多100 MiB，重进页面/重启可复用，删除原书时清理，不进入JSON/WebDAV备份。缓存可被系统清理，准备速度不足时仍可能短暂缓冲。iOS系统文件合成尚未接入。

教材「认一认」直接展示2～4列生字卡：上半区朗读单字，下半区朗读完整词句，留白也可点；只按句末标点分句，复用教材私有音频缓存。每张卡右下角浮动显示无背景的「去认字 ›」，点击后检查语音识别密钥，已保存完整密钥即可练习所点的这个字，否则打开语音识别设置，不强制先做录音测试。主动选字不受复习日期限制，先隐藏拼音独立认读，不要求家长核对或抽查。练习页隐藏导航栏，返回按钮固定在原位；字卡缩小上移、字的大小不变，展开的拼音在字上方，说明与示范以图标上下排列在卡片外侧右边。点击「读一读」录音，不再提供认读自评按钮。提示、辨认和自动认读分别记录，历史自评保留；跨天复测才推进复习，一次通过不表示永久掌握。原有本机历史记录保留。

教材「写一写」右上角的「听写」按本课会写字每轮随机、不重复报题，支持纸上听写与屏幕手写。优先播放与教材读音一致的课内词句并指定目标位置，缺少语境时只报字音；听写中隐藏字形与拼音，整轮结束后统一展示标准字和逐题笔迹，由家长核对，可只练错字或全课重来。纸笔模式可手动推进或在每题播报结束后间隔10/15/20/30秒自动推进；屏幕手写支持撤销、清空、跳过和旋转缩放。暂停、后台或页面遮挡停止自动推进，返回前提示本轮不保留。笔迹与对错仅留在本轮内存，不上传、不备份，不自动计入既有描红或掌握记录；播报复用系统/可选云朗读与教材音频缓存。

认字复用「设置 → AI 与语音 → 语音识别设置」中已保存的腾讯云识别密钥，APPID 默认自动获取，无需独立口语评测配置；诗词跟读仍需通过真实录音测试。孩子主动录音时，优先按实时协议发送当次 PCM（16kHz/16bit/单声道，最多10秒）；仅当腾讯云明确返回实时资源包耗尽时，录音结束后改用一句话识别。只识别录音，不发送答案字、拼音或目标热词。单字按同音同调匹配；多音字请孩子自己组词，读音不明确时重读，不直接确认。结果只表示本次认读匹配，不是专业发音评分；静音、超时或不确定结果不记对错，听示范后通过仅记提示练习。缺读音时保留自练。录音仅在内存临时使用，退出或后台取消；请求计入已有语音识别日额度，实时资源耗尽后的回退复用本次额度计数。真实儿童录音效果需在配置后体验确认。

识字记录随Hive加密保存在本机，不进入JSON/WebDAV备份；恢复保留累计记录但使旧轮次失效，移除PDF保留识字记录，同版重导可复用，卸载可能丢失。语音识别验证绑定本机，换机需重新测试。

识别文本无法直接证明实际声调或口音准确；多音词消歧依赖现有课内注音或词典，缺少明确语境时保留自练，不猜测通过。

语音识别设置页进入时只读取一次设备安全存储，首帧直接显示设置结构。打开页面
不会请求腾讯云或麦克风权限，录音仅在真实录音测试、诗词跟读、认字或看图说话开始时触发；测试
通过即视为已配置，修改或删除密钥会立即撤销该状态。

及文件选择器的间接依赖 `flutter_plugin_android_lifecycle 2.0.35`，不支持 Android 5/6。
调整前需评估旧设备影响，调整后运行 `python3 tools/check_android_compatibility.py`；
测试和发版 CI 均执行此检查。本地 `AGENTS.md`、模拟器指南存在时也会参与检查。

### 快速开始

```bash
# 克隆项目
git clone <repo-url>
cd PoeMath

# 安装依赖
flutter pub get

# 运行
flutter run

# 运行测试
flutter test

# 静态分析
flutter analyze

# 检查 Android 最低版本的配置与文档一致性
python3 tools/check_android_compatibility.py
```

正式发布包仅包含 `arm64-v8a`，适用于绝大多数现代 Android 真机。除了构建命令
指定 `--target-platform android-arm64`，Release 构建还会在 Gradle 打包层过滤
第三方插件传递引入的其它 ABI 的 JNI 库，保证安装包只含 `arm64-v8a`。32 位 ARM
设备和 x86_64 模拟器不在正式发布包的支持范围内，Debug 构建不受此限制。

质量门禁使用项目 FVM 的 `flutter analyze` 和 `flutter test`，具体结果记录在 `.trellis/tasks/` 的验收文档中。Android/iOS 真机录音、系统备份恢复需单独验证。

## CI/CD

项目配置了两条 GitHub Actions 流水线：

### 自动测试（push / PR）

每次 push 到 `main` 或提交 PR 时自动触发：

```
Android 最低版本一致性检查 → analyze → test
```

在 GitHub 仓库的 **Actions** 页面查看运行状态。

### 自动构建发版（tag）

打 `v*` 格式的 tag 时自动触发完整构建并发布到 GitHub Release：

```
Android 最低版本一致性检查 → analyze → test → build ARM64 release APK → 创建 GitHub Release
```

#### 使用方式

```bash
# 1. 推送代码，等 CI 测试通过
git push origin main

# 2. 打 tag 触发构建
git tag v1.0.0
git push origin v1.0.0
```

构建完成后在 [Releases](../../releases) 页面下载 APK。

#### 版本号规则

- tag 必须为 `v主版本.次版本.修订号`，次版本和修订号均为 0–99，无前导零；`v1.2.3` → 版本名 `1.2.3`、构建号 `10203`，新发布构建号必须递增
- 应用内「我的」页面底部自动显示当前版本号

#### 签名配置

使用固定签名密钥，确保每次构建的 APK 可覆盖安装。需在 GitHub 仓库 **Settings → Secrets → Actions** 中配置：

| Secret | 说明 |
|--------|------|
| `KEYSTORE_BASE64` | base64 编码的签名文件 |
| `KEYSTORE_PASSWORD` | keystore 密码 |
| `KEY_ALIAS` | key 别名 |
| `KEY_PASSWORD` | key 密码（**必须与 `KEYSTORE_PASSWORD` 相同**） |

> ⚠️ **重要**：Java 9+ 的 keytool 默认生成 PKCS12 格式的 keystore，PKCS12 **不支持 storePassword 和 keyPassword 不同**。即使创建时指定了不同的 `-keypass`，也会被静默忽略。因此 `KEY_PASSWORD` 和 `KEYSTORE_PASSWORD` 必须设置为相同的值。

生成签名密钥：

```bash
keytool -genkey -v \
  -keystore poemath-release.jks \
  -alias poemath \
  -keyalg RSA -keysize 2048 \
  -validity 10000 \
  -storepass YOUR_PASSWORD \
  -keypass YOUR_PASSWORD \
  -dname "CN=PoeMath, O=PoeMath, L=Beijing, C=CN"

# 转 base64 后填入 KEYSTORE_BASE64（从文件复制，避免终端截断）
base64 -i poemath-release.jks -o keystore.b64
cat keystore.b64 | pbcopy
```

### 应用内更新（阿里云 OSS）

应用支持检查新版本、下载 APK 并安装。更新文件托管在阿里云 OSS，CI 构建时自动上传。

#### 工作流程

```
打 tag → CI 构建 APK → 上传到 OSS → 生成 latest.json
→ 启动/恢复前台自动检查（至少间隔一小时）或手动检查 → 对比版本 → 用户确认下载 → SHA-256 校验 → 用户确认安装
```

| Secret / Variable | 说明 | 示例值 |
|-------------------|------|--------|
| `ALIYUN_OSS_ACCESS_KEY_ID` | 阿里云 AccessKey ID | `LTAI5t...` |
| `ALIYUN_OSS_ACCESS_KEY_SECRET` | 阿里云 AccessKey Secret | `***` |
| `ALIYUN_OSS_ENDPOINT` | OSS Endpoint | `oss-cn-hangzhou.aliyuncs.com` |

#### 课本学习

从「设置 → 学习与内容 → 书籍管理」管理所有册次，导入本地 PDF 或从真实封面网格下载 12 册公开来源教材。按实际版本选择，2022 课标修订与旧版分别标注，缺失的出版年月不作推断；下载支持进度、取消、重试和文件校验，完成后可离线阅读。

## 隐私政策

韵算严格保护用户隐私。**完整政策**以应用内资源为准：

- `assets/legal/privacy_policy.md`（「我的 → 关于 → 隐私政策」读取此文件）

要点：

- ✅ **离线优先**：核心学习不依赖网络，飞行模式可用
- ✅ 不收集个人信息到开发者服务器；无广告 / 分析 / 追踪 SDK
- ✅ 无内购或付费功能
- ✅ 诗词跟读使用腾讯云识别，属可选能力：家长需在「AI 与语音 → 语音识别设置」填写 AK/SK 并通过真实录音测试后才启用；未配置时跟读入口置灰并引导配置
- ✅ 云端朗读音色同为可选能力：家长在音频设置中填写自建服务地址与 API Key，验证通过后开启，默认关闭；开启后向该服务发送朗读文本。教材包含当前段及最多后两段的提前准备，音频在本机私有缓存目录复用（100 MiB上限）；其他云朗读仍仅用内存缓存。云合成失败回退系统音色，教材无法生成或播放时停在当前段提示重试
- ✅ 本机历史快照始终使用设备密钥加密；JSON / WebDAV 备份设置口令后加密整份学习记录、聊天内容与凭据，未设置口令时以明文导出且不含凭据；加密备份需同一口令解包，随后可选择跳过凭据恢复；WebDAV 用户名/密码始终不进入备份
- ✅ 看图说话题图与录音在应用私有目录保存，未额外加密；题图进入应用备份，录音与练习历史留在本机。家长为助手配置支持图片的 AI 模型后，完成练习时会向所配置服务发送完整题图、表达文字和练习目标，可能按自动切换规则发送至其他已配置服务商
- ✅ 学习数据主要保存在本机；Android 可能按系统设置备份或迁移，WebDAV / 腾讯云识别 / 云端朗读 / 通知需用户主动操作或授权；配置更新源后启动及恢复前台自动检查版本（至少间隔一小时），下载与安装需确认
- ✅ 权限与行为对照见隐私政策正文（含 `INTERNET`、麦克风、通知、安装 APK 等说明）
- ✅ 联系方式：应用内关于页；开源发行可通过仓库 Issue（客服邮箱待渠道确定后补充）
